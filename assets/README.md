# Mudasir Javid - Portfolio Assets & Deployment Guide

This folder contains the styling, interactive scripts, and image assets for Mudasir Javid's personal portfolio.

## 1. Profile Picture (`1.png`)
- Place your personal photo directly inside this `assets/` folder with the filename `1.png`.
- Recommended specifications:
  - Resolution: 400x400 px or 512x512 px (Square 1:1 aspect ratio)
  - Format: PNG or JPG (keep name as `1.png`)
  - The website includes an automated fallback badge ('MJ') if the file is ever missing or loading.

## 2. Deploying to GitHub Pages
1. Push this repository to your GitHub account (e.g., `https://github.com/MUDASIR-JAVID/MUDASIR-JAVID.github.io` or `https://github.com/MUDASIR-JAVID/portfolio`).
2. Ensure the following files are in the repository root:
   - `index.html` (Home page)
   - `about.html` (About page)
   - `resume.html` (Experience & Skills)
   - `portfolio.html` (Projects showcase)
   - `contact.html` (Contact form & details)
   - `assets/style.css`
   - `assets/main.js`
   - `assets/1.png`
3. On GitHub, go to your repository's **Settings** → **Pages**.
4. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
5. Click **Save**. Within 1–2 minutes, your website will be live at `https://mudasir-javid.github.io/`!
